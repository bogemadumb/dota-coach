# Dota Coach — живые подсказки в Dota 2

Локальный ассистент, который сидит рядом с запущенной Dota 2 и по ходу матча подсказывает голосом и на втором экране:
тайминги рун и стаков, что покупать дальше с учётом всех десяти героев, как играть против конкретного соперника.
Разбор после матча не делается сознательно — только то, что полезно прямо сейчас.

## Как устроено

```
Dota 2 ──GSI (HTTP POST, JSON)──► gsi_server ──GameState──┬─► timers ─────────────┐
                                                          ├─► events               ▼
data/counters.yaml ──правила контр-предметов──► items ─────┼─► match_picture ──► brain ──► arbiter ──► voice
                                                          │                       │
                                                          └───────────────────────┴────► panel (WebSocket)
```

- **GSI** — официальный канал Valve Game State Integration: клиент игры сам шлёт состояние на `127.0.0.1:3001/gsi`.
  Сервер (FastAPI) проверяет токен из конфига и раскладывает данные в `GameState`.
- **timers** — тайминги по правилам из `data/timings.yaml`, без модели: задержка меньше секунды и ноль токенов.
  Измерение показало, что `claude -p` отвечает за 7–10 с, — для «руна через 10 секунд» это бесполезно.
- **match_picture / items** — картина матча и советчик по предметам: что уже видно у врагов и союзников,
  перевес по фарму, правила контр-предметов (`data/counters.yaml`).
- **brain** — постоянная сессия Claude через Claude Agent SDK со своим системным промптом
  (`src/dota_coach/prompts/brain_system.md`). В контекст кладётся справочник механик и карточки героев
  текущего драфта (~12k токенов); при смене драфта сессия пересобирается.
- **arbiter** — решает, что и когда сказать: приоритеты, время жизни совета, защита от повторов,
  режимы «тихий / обычный / болтливый».
- **voice** — `say` macOS; **panel** — страница на втором мониторе, получает советы по WebSocket.

## База знаний и проверка фактов

Модели нельзя верить на слово про числа и взаимодействия способностей, поэтому знания собраны в базу
и проверяются автоматически:

| Шаг | Инструмент | Что делает |
|---|---|---|
| Официальные данные патча | `tools/update_official.py`, `tools/build_kb.py` | герои, способности, предметы → `data/kb/heroes`, `data/kb/items` |
| Сверка | `tools/diff_kb_dotaconstants.py` | сравнение с открытым набором dotaconstants |
| Сборки | `tools/fetch_builds.py`, `tools/fetch_stratz.py` | статистика сборок по позициям (генерируется локально, в репозиторий не входит) |
| Карточки | `tools/build_cards.py` | 127 полных и 127 коротких карточек героев для контекста модели |
| Проверка фактов | `tools/factcheck.py` | 154 + 155 вопросов с эталонами из официальных данных |

В репозиторий входят открытые кэши, без которых сервер не стартует (`data/cache/dotaconstants`, `data/cache/opendota`,
схема STRATZ) и собранные карточки. Статистика сборок (`data/kb/builds*`) и сырой datafeed генерируются локально;
тесты, сверяющие генераторы с этими данными, без них пропускаются.

Замер на независимом банке вопросов: без базы модель отвечает верно в 47 % случаев, с карточками — в 97–99 %.
Отчёты лежат в `data/kb/factcheck/`.

## Запуск

```sh
uv sync
uv run pytest -q                 # 332 passed, 15 skipped; настоящую модель тесты не запускают — conftest подменяет клиента
uv run python tools/simulate.py  # проигрывает синтетический матч в локальный GSI-сервер
uv run dota-coach                # сервер на 127.0.0.1:3001, панель — http://127.0.0.1:3001/
```

Для живой игры в папку `dota 2 beta/game/dota/cfg/gamestate_integration/` кладётся конфиг GSI с адресом
`http://127.0.0.1:3001/gsi` и токеном из `config.yaml` (по умолчанию `dota-coach-local`). Для модели нужен
залогиненный Claude Code (Agent SDK использует его авторизацию).

## Стек

Python 3.12, FastAPI, asyncio, Claude Agent SDK, PyYAML, pytest; uv для окружения.

## Данные третьих сторон

`data/kb/heroes`, `data/kb/items` построены из официального datafeed Dota 2 и сверены с dotaconstants;
справочник механик (`data/kb/mechanics_*.md`) ссылается на Liquipedia (CC BY-SA). Dota 2 — товарный знак Valve.
Проект не читает память игры и не меняет её файлы.
